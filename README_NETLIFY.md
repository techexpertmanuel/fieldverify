# Quick deployment

1. Push this project to GitHub.
2. Import the repository into Netlify.
3. Netlify reads `netlify.toml`.
4. Add production variables from `.env.netlify.example`.
5. Deploy.
6. Check `/api/health`.
7. Install the PWA on Android using Add to Home Screen.

See `DEPLOYMENT_GITHUB_NETLIFY.md` for the full guide.
